# 🐾 Cocina de Negro & Mechy • Calculadora de Rendimiento Canino

Una aplicación web moderna, minimalista y diseñada con enfoque **Mobile-First** para calcular gramos exactos de alimento en **CRUDO** que se deben pesar antes de cocinar, según la pauta nutricional veterinaria exigida en **COCINADO**. 

Dedicada con amor para **Negro 🐕‍🦺**, **Mechy 🐩** y su chef **Vanessa ❤️**.

---

## ✨ Características Principales

- **Fórmula de Rendimiento Calibrada:**  
  $$\text{Gramos en Crudo} = \frac{\text{Gramos Cocinados Deseados}}{\text{Factor de Rendimiento}}$$
- **Categorías con Factores Veterinarios Exactos:**
  - **🥩 Proteínas (Merman al cocinarse por deshidratación y grasa):**
    - Sobrebarriga / Res (0.65)
    - Pechuga de pollo (0.75)
    - Muslo/Contramuslo deshuesado (0.70)
    - Hígado de res o pollo (0.68)
    - Lomo de cerdo magro (0.72)
    - Pescado blanco (0.75)
  - **🍚 Carbohidratos (Absorben agua y aumentan de peso):**
    - Arroz blanco / integral (2.80)
    - Avena en hojuelas (3.20)
    - Papa / Camote al vapor (0.95)
  - **🥦 Verduras Aconsejadas:**
    - Zanahoria / Auyama (0.85)
    - Calabacín / Zucchini (0.75)
    - Espinaca cocida (0.70)
    - Brócoli al vapor (0.85)
- **Modo Batch Cooking / Sesión de Cocina:**
  - Multiplicador de porciones para **1 día**, **4 días** y **8 días**.
  - Totalizador automático de gramos crudos a descongelar / pesar.
  - Botón para copiar la lista formateada lista para enviar por **WhatsApp** o guardar en Notas.
- **Mobile-First UI & Ergonomía:**
  - Diseñada para usarse con una sola mano en la cocina.
  - Paleta estética y cálida: tonos crema, terracota y verde salvia.
  - Botones rápidos de acceso táctil (+25g, +50g, +100g, presets de porción y reset).
  - Modal con la tabla de factores y consejos de cocción segura.

---

## 🚀 Despliegue / Uso

Al ser un **Single File HTML** (`index.html`) con Tailwind CSS y Vanilla JS, no requiere instalación ni dependencias:

1. Abre directamente el archivo `index.html` en cualquier navegador de móvil o escritorio.
2. O habilita **GitHub Pages** en la configuración del repositorio (`Settings > Pages > Branch: main`) para tener la app publicada online de forma gratuita.
